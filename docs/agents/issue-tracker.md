# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues in `ccpowe/ruyi-agent`.
Use the `gh` CLI for issue operations from inside this clone.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List issues with `gh issue list`, adding state, label, and JSON filters as needed.
- Comment with `gh issue comment <number> --body "..."`.
- Apply or remove labels with `gh issue edit`.
- Close an issue with `gh issue close <number> --comment "..."`.

When an engineering skill says to publish work to the issue tracker, create a
GitHub issue. When it asks for the relevant ticket, read the matching GitHub
issue and its comments.
