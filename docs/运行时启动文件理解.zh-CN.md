# Runtime Bootstrap 当前实现

`src/ruyi_agent/runtime/bootstrap.py` 是进程级装配入口。它只负责创建、连接和释放长生命周期对象，不拥有 Gateway Task 或 Channel Turn 的业务策略。

## 启动顺序

```text
configure runtime environment
  -> create Backend Runtime
  -> scan Skills
  -> load Agent / Provider / Permission / MCP configs
  -> refresh MCP Registry
  -> open Checkpointer and SQLite Stores
  -> build Local Agent Specs and Remote Refs
  -> attach per-Agent delegation scopes
  -> create one AgentControl
  -> create GatewayTaskModule
  -> yield AppRuntime
```

退出 `bootstrap_application()` 时关闭 RouteStore、TaskStore、ReviewAuditStore、Checkpointer 和 Backend Runtime。

## 唯一 AgentControl

所有成功构建的 Local Agent 和 Remote Ref 都登记进同一个 `worker_control`。它同时服务 public root Task 和内部 Subagent Task，保证父子 Task 使用同一 TaskManager、任务预算和恢复存储。

每个 Agent 能委派给谁，仍由 `agents.toml` 的 workers 配置和 scoped delegation tools 限制。

Public 可见性由 `GatewayTaskModule` 根据 Agent 配置校验，不再存在 public-only `gateway_control`。

## Agent 构建隔离

本地 Agent 按配置逐个构建。某个 Agent 因模型凭据或配置失败时：

- 其他 Agent 继续注册。
- Gateway 仍可启动。
- public Agent 列表显示该 Agent 不可用及原因。
- 为其创建 Task 返回 `agent_unavailable`。
- 它不会进入可委派 Local Agent scope。

## AppRuntime

`AppRuntime` 保存 Channel Adapter 和 Gateway 生命周期共同需要的对象：

- `gateway_service`：实际类型为 `GatewayTaskModule`。
- `worker_control`：唯一 `AgentControl`。
- Agent 配置与已构建 Local Specs。
- Checkpoint、Route、Task 和 Review Audit 数据库位置。
- Skill Catalog 与 SkillSyncer。
- Permission 默认 profile。

字段名 `gateway_service` 是当前运行时容器属性名，不代表 Gateway Task Module 属于 HTTP 层。

## FastAPI 生命周期

`create_bootstrapped_gateway_app()` 创建 FastAPI Adapter，并在 lifespan 中进入 `bootstrap_application()`：

```text
FastAPI lifespan
  -> bootstrap_application
  -> app.state.app_runtime
  -> app.state.gateway_service
  -> attach_gateway_routes 调用 Gateway Task Interface
```

默认开发 token 只允许绑定 loopback 地址；对外监听必须显式配置安全的 `GATEWAY_BEARER_TOKEN`。

## 已删除路径

当前 Bootstrap 不再组装：

- TUI 或本地交互 root runner。
- `ProtocolController`。
- `gateway_control`。
- `AgentControlGatewayRuntime` 转发 Adapter。
- 单独的 root Agent 会话缓存。
